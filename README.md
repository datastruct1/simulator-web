# Simulator Web

基于 **Vue 3 + Vite + TypeScript** 的甲醇燃料模拟器 Web 界面复原项目。

以同仓库的 WPF 项目为参考：保留工艺图布局、设备编号、原图标、中文导航和流程规则，并将窗口、控件与业务页面拆成 Vue 组件。当前所有交互在浏览器内运行，**不连接后端、PLC、加密狗或 WPF 物理仿真引擎**。

## 启动

需要 Node.js **22.12+**（推荐 Node 22 LTS）。在本目录打开终端：

```bash
npm install
npm run dev
```

浏览器打开 **http://localhost:5173**。

- 登录页可选择教师直接进入、学员演示、离线仿真。
- `http://localhost:5173/?demo=1` 可直接进入教师视图，方便界面调试。
- 学员身份证输入仅做前端格式检查，不上传数据。

```bash
npm run typecheck   # Vue / TypeScript 类型检查
npm test            # 设备规则、原阶段判分、任务/会话/存储和场景资源测试
npm run build       # 生成 dist/
npm run preview     # 预览构建产物
npm run test:e2e    # 浏览器交互测试
```

浏览器测试在 Windows 上优先使用本机 Chrome / Edge；其他环境可先运行 `npx playwright install chromium`。也可通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 指定可执行文件。

## 界面与操作

### 工艺仿真

保留 10 张 WPF 主工艺界面：

| Web 页面 | WPF 来源 |
| --- | --- |
| 系统总览 | `Views/Main/IndexView.xaml` |
| 氮气供应撬块 | `NitrogenCompartmentView.xaml` |
| 加注前端撬块 | `BeforeAddView.xaml` |
| 加注撬块 | `AddPartView.xaml` |
| 燃料舱隔离空舱 | `FuelSiloPartView.xaml` |
| 燃料准备间 | `LFSSPartView.xaml` |
| 甲醇发动机机舱 | `DynamoPartView.xaml` |
| 冷热水撬块 | `WaterPartView.xaml` |
| 回收撬块 | `RecyclePartView.xaml` |
| 总控室 | `GeneralControlView.xaml` |

工艺图由原 XAML 转换为 SVG 场景，不是静态截图。原 Canvas 坐标、管线、阀门编号、设备图片、区域边框、仪表和导航按钮保存在生成数据中。

- 点击设备打开操作窗口；右键可查看快捷操作。
- 阀门支持开关、开度、手轮角度与三通阀方向。
- 泵、风机、发动机、加热器支持启停和运行参数编辑。
- 三根加注软管与 `Rg001 / Rg002 / Rg003` 规则联动。
- 各撬块开泵、关泵、急停、复位按钮作用于该撬块设备；冷热水急停关闭两泵六阀、锁定面板，复位不启动泵或清除独立设备故障。
- 传感器支持量程、数值、四级阈值、冻结更新和告警配置。
- 工艺图支持缩放、拖动和适配视图，设备高亮定位。
- 原 XAML 大写 DisplayId 与原传感器 / 软管编号共享设备状态，量程、单位、阈值和图元数值不会各自漂移。
- 活动告警播放随项目提供的原警报音，消音、全部确认及退出会停止声音；受浏览器自动播放限制时，在下一次用户交互后重试。

### 流程、安全检查和工况

- 21 个流程：岸载/船载惰化、加注、加注扫气、甲醇供应、供应扫气、冷热水调节、泄漏处置、泵故障切换、各类回收、排岸、负载均衡和停止。
- 308 个前端演示 / 操作提示步骤，来源于 10 套 WPF 操作题及原工况快照。
- **判分与演示进度分离**：10 套原 Playbook 保留 20 个评分阶段、139 条 Conditions / Triggers 规则。全部触发器同时满足才结算阶段，条件逐项得分；条件失败不阻塞阶段、也不在交卷时补分。
- 自动演示不能代替手动考核。原权重、消息、来源和值保留；不合法权重用确定性回退归一化，并在成绩说明中记录修正。
- 演示支持倍速、暂停、下一步和完整提示；限时操作考评隐藏演示 / 正确操作提示 / 调试入口，真实考评时钟不受仿真倍速和暂停影响。
- 九个安全检查 tab，检查项、双方确认、数据填写及签收校验；惰化和加注有前置门禁。
- 20 组原 WPF 工况；保存、导出和载入 Web 工况 JSON。

### 教学与业务工作台

教师、学生、练习 / 考评和操作题编辑器均有实际页面，不再使用缺失组件占位。题库、任务、组卷、文件、成绩使用浏览器本地持久化，支持页面编辑及导入导出。

- **学生主页**：已发布 / 指派任务、详情和附件、理论练习（标签 / 试卷 / 错题 / 收藏）、操作练习、学习资料与历史成绩。
- **理论作答**：单选 / 多选 / 判断、上一题 / 下一题、答题卡、收藏、练习答案解析、未答确认交卷、真实计时和自动交卷。答案与原截止时间跨页面 / 刷新保留。
- **单机练习 / 考评**：原 T11 / T12 菜单、学号姓名录入、原操作 / 故障目录、注意事项、实际结果与错题重练。只有名称而没有独立规则的原条目标记待教师配置，不伪造成完整考评。
- **操作题编辑器**：状态 / 事件组 / 嵌套逻辑条件 / 得扣分与转移动作、初始及事件工况、设备设置、顺序操作和手动录制、校验保存、JSON 往返及本地测试。

理论按实际答案及权重计分；自编状态题按事件记录、顺序题按实际手动序列的 LCS 匹配计分。工况派生条目使用本地步骤评估，明确区别原 Playbook 阶段。点击“返回考核”或顶栏“提交操作考核”可完成操作交卷。隐藏成绩不参与学员均分、答案详情及导出；删除历史成绩不解除已提交任务的重考限制。

刷新后的操作考核会保留原时限、手动记录及阶段结果，但工艺设备未保存为完整运行快照，必须重新初始化工艺再继续；不会把刷新后的初始设备当作已完成操作。

### 二级工具

底部“更多操作”提供：设备监测、实时趋势、传感器设置、异常配置、通风系统、物品柜、系统日志、操作记录、加载/保存工况、设置、系统介绍、仿真调试和场景编辑器。

物品柜包含 40 个原单体 OBJ / 3DS 模型及相关材料/图片，模型可旋转和缩放；只按需加载选中模型。字体、图标、图片和模型都随项目提供，不依赖在线图片服务。

## 组件和数据结构

```text
src/
  App.vue                    入口、窗口宿主、WPF 命令适配
  components/
    LoginView.vue            登录窗口
    common/                  弹窗、图标、表格、趋势曲线
    layout/                  顶栏、导航、状态栏、流程选择和进度
    scene/                   原 XAML 工艺图渲染、设备图元、几何计算
    safety/                  九类安全检查和签收表
    dialogs/                 设备操作与系统工具窗口
    workspace/               教师、学生、考试、场景编辑器
  state/
    simulator.ts             共享设备/流程/工况/告警/日志状态
    engine.ts                纯前端规则判定、设备操作和工况校验
    workspace.ts             本地教学和考核状态
  data/
    scenes.generated.json    10 张原 XAML 场景
    workflows.generated.json 原流程、设备初值、工况
    questions/               原题库本地副本
    tools.ts                 原传感器/检查/阀门等配置
    workspace.ts             教学领域数据
public/assets/               原 WPF 图片、字体、音频、单体模型
scripts/                     WPF 资源导入脚本
tests/                       单元测试和 Playwright 浏览器测试
```

状态与视图分离；大业务工作台和 3D 视图按需加载。后续接后端时可在 state / 服务层替换本地数据来源，不需要重新绘制工艺图。

本轮补齐范围、测试和仍需接入的桌面能力见 [IMPLEMENTATION_STATUS.md](docs/IMPLEMENTATION_STATUS.md)。

## 从 WPF 重新同步

生成数据、题库与资源已经随项目保存，日常运行 **不需要 Python 或 .NET**。只有重新导入同仓库 WPF 修改时才需要 Python 3：

```bash
npm run import:wpf
```

该命令只读 WPF，更新本 Web 项目的生成数据和资源。大型聚合模型（约 174MB 的 `17.obj`、约 22MB 的模型组）不导入；单体模型保留。

## 当前边界

- 这是交互式界面与流程复原，不是 WPF 控件运行时移植；部分控件采用 SVG/CSS 重绘，浏览器排版与桌面原控件不会逐像素相同。
- 数值变化是用于展示的前端趋势，不调用真实热力学、管网或介质求解器；不能用于设备操作、工程计算或正式认证考核。
- 服务器、PLC、图传、发布任务等不会产生真实网络业务。界面明确标示本地模式。
- 原题库/脚本中的文案、答案、单位和缺省参数可能存在历史问题，教学使用前应校核；来源路径保存在生成数据中。
- 本地记录保存在当前浏览器；浏览器清理数据后会丢失，请使用导出功能备份。
- 当前资源路径以站点根目录部署为前提；静态部署时需使用 HTTP 服务，不能直接双击 `dist/index.html`。

详细映射见 [WPF_PARITY.md](docs/WPF_PARITY.md)。
